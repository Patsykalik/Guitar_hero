                                                            🎸 Guitar Hero Clone (Qt C++)
Это простая ритм-игра, написанная на C++ с использованием фреймворка Qt. Игрок должен нажимать на клавиши в такт падающим нотам, чтобы набирать очки.

                                                                    🕹 Геймплей
Механика: Ноты (шарики) выпадают на четырех струнах сверху вниз.  Управление: Используйте клавиши 1, 2, 3 и 4 для «попадания» в ноты, когда они пересекают красную линию в нижней части экрана. Настройки: Можно выбрать количество струн (1–4) и аудио-трек в меню настроек.  Скринсейвер: В проекте есть бонусный режим «Rock Screen Saver» с анимацией гитариста и усилителя.  🛠 стек: C++ (C++17 и выше). Qt 6 (используются Widgets, Gui, Multimedia и GraphicsView).  Сборка: CMake.  Структура проекта game.cpp — Точка входа в приложение, инициализация главного окна.  interface.h / interface.cpp — Описание UI-компонентов: главного меню, настроек и окна заставки.  gameplay.h / gameplay.cpp — Ядро игры: логика движения нот, обработка нажатий клавиш и расчет очков.  game.cpp — Глобальные настройки конфигурации игры.

# 🎸 Guitar Hero

Современная музыкальная rhythm-game, созданная на C++ и Qt6.

Проект вдохновлён серией Guitar Hero и реализует полноценный игровой процесс:
игра под музыку, падающие ноты, систему очков, комбо, таблицу лидеров,
настройки, заставку и современный неоновый интерфейс.

---

# 📸 Скриншоты

## Главное меню
- выбор песен
- запуск игры
- настройки
- таблица лидеров
- заставка

## Игровой процесс
- наклонный гриф
- анимированные ноты
- система попаданий
- эффекты PERFECT / GOOD / MISS
- счёт, комбо и жизни
- пауза игры

## Таблица лидеров
- сохранение результатов в SQLite
- имя игрока
- песня
- очки
- дата игры
